# Phase 013: Domain-Agnostic Compositional Invariants

## 1. Objective
Establish universal, domain-agnostic invariant deconstruction across technical, scientific, legal, medical, and linguistic disciplines. Ensure all concepts decompose into transparent compositional primitives adhering to the 2-second working memory limit.

---

## 2. Invariants & Rules
1. **Domain Agnosticism**:
   The compiler and optimizer must process arbitrary domains (STEM, Law, Medicine, Philosophy, Languages) without domain-specific hardcoding. Every domain is decomposed into:
   - Core Causal Invariant (The non-negotiable rule).
   - Boundary Conditions (Where the rule collapses).
   - Observable States (Empirical evidence).
2. **Compositional Transparency (The Base-10 Insight)**:
   Avoid opaque monolithic jargon. Deconstruct complex ideas into transparent combinations of upstream DAG nodes (analogous to $11 = \text{shí-yī}$ / $10+1$).
3. **Phonological Loop Working Memory Budget**:
   Forward-pass challenge prompts are capped at $\le 50$ words ($\le 3$ seconds silent reading) to prevent working memory thrashing before prediction.
